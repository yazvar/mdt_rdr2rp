# Администрирование

Админ-панель видна только роли с правом `admin.access`. Действия с доступом, ролями, настройками, финансами и архивом пишутся в журнал. Журнал из обычного окна не очищается.

## Допуск

1. Создайте карточку сотрудника: имя, фамилия, уникальный табельный номер, звание.
2. В админ-панели введите числовой Discord ID, выберите должность и эту карточку.
3. Сотрудник входит через Discord. Пока допуск не выдан, OAuth завершается отказом.

Тестовые персонажи `TEST-DISCORD-*` через эту форму не привязываются: Discord ID в форме только из цифр.

Блокировка гасит сессии. Снять блокировку можно отдельно. «Сессии» выгоняет человека из открытых окон, не отбирая должность. Последнего администратора заблокировать или лишить роли нельзя.

## Должности

Системные роли уже созданы. Их ключи не меняются. Набор прав меняется во вкладке «Роли» и начинает действовать сразу: сокеты затронутых людей отключаются.

Стартовая матрица записана в данные, а не зашита в кнопки. Если у роли ещё нет ни одного права, при старте API ей выдаётся этот набор. Уже изменённая роль при следующем запуске не затирается.

| Модуль | Заместитель | Помощник шерифа | Шериф | Администратор |
|---|---|---|---|---|
| Сотрудники | Просмотр | Управление | Управление | Полный доступ |
| Вооружение | Только своё | Управление | Управление | Управление |
| Утеря | Только своё | Управление | Управление | Управление |
| Конфискат | Просмотр | Управление | Управление | Полный доступ |
| Законы | Просмотр | Правка без отмены и импорта | Управление | Управление |
| Розыск | Просмотр | Создание и обновление | Полный доступ | Полный доступ |
| Штрафы | Просмотр и выдача | Управление | Полный доступ | Полный доступ |
| Запросы | Создание | Рассмотрение | Полный доступ | Полный доступ |
| Казна | Нет | Просмотр | Полный доступ | Полный доступ |
| Админ-панель | Нет | Нет | Нет | Полный доступ |

Старший помощник шерифа по умолчанию совпадает с шерифом, без админ-панели. Наблюдатель видит те же разделы, что заместитель, но не выписывает штрафы и не создаёт запросы. Сумму штрафа меняет только тот, у кого есть право корректировки, и только с причиной.

Шериф назначает служебные роли из карточки сотрудника. Роль администратора выдаёт только администратор.

## Законы

В архиве лежит сборник сервера. Тестовые статьи в рабочую базу не входят. Новую статью добавляют вручную или импортом.

Импорт принимает JSON-массив или CSV. Колонки: `articleNumber`, `title`, `category`, `description`, `conditions`, `fineCents`, `jailDays`, `additionalPenalties`, `status`. `fineCents` — целое число центов. Режим импорта в окне — обновление по номеру статьи. Отмена статьи и импорт требуют права управления законами.

## Казна

Проводку создаёт сотрудник с правом управления казной. Баланс на экране — пересчёт всех проводок, его нельзя напечатать вручную. Оплаченный штраф проводится в доход, только если включена соответствующая настройка. Отмена оплаченного штрафа создаёт расход на ту же сумму. Стоимость снаряжения списывается при выдаче только если включена вторая настройка.

Отчёт за день, неделю и месяц выгружается в CSV. Границы дня считаются по `TZ_OFFSET_MINUTES`.

## Уведомления

Во вкладке настроек можно выключить виды писем, указать дополнительные Discord ID получателей и сервер для справки. Письмо уходит, только если событие включено и у человека открыты личные сообщения от бота.

## Демонстрационные данные

Кнопка «Архивировать тестовые записи» закрывает оставшиеся строки с пометкой демонстрации: розыск, запросы, штрафы, склад и тестовые статьи. Рабочая база после очистки таких строк не содержит.

## Обновление программы

Во вкладке «Обновление» администратор указывает следующую версию и отправляет новый установщик Windows. Сервер сохраняет файл и сообщает всем открытым программам. Они показывают «Доступно обновление», скачивают сборку и перезапускаются. «Позже» откладывает перезапуск до закрытия окна. Сотрудник, который не был в сети, получает обновление при следующем входе.

Первую сборку с этой возможностью нужно поставить вручную. Более ранний установщик сам не обновится.

## Ошибки

Вкладка «Ошибки» показывает сбои API и бота без токенов. Туда попадает отказ Discord отправить личное сообщение и необработанное исключение запроса.
