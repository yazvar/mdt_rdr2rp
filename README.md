# Шерифский MDT

Настольный архив шерифского департамента для Red Dead Redemption 2 Roleplay. Сотрудники ставят приложение на Windows. База, API и Discord-бот работают на [Railway](https://railway.com) и обслуживают всех сразу.

## Состав

| Часть | Папка | Назначение |
|---|---|---|
| Приложение | `apps/desktop` | Electron, React, TypeScript |
| API | `apps/api` | Express, сессии, права, Socket.IO |
| Бот | `apps/bot` | Личные сообщения Discord и slash-команды |
| Общий код | `packages/shared` | Права, деньги, схемы проверки |
| База | `prisma` | Схема PostgreSQL и миграции |

Настольное приложение не подключается к PostgreSQL и не содержит секрет Discord или токен бота. Адрес API задаётся при сборке через `VITE_API_URL`.

## Что нужно локально

- Node.js 20 или новее
- PostgreSQL 15 или новее
- Учётная запись Discord, если проверяете настоящий вход

## Первый запуск

```bash
npm install
copy .env.example .env
```

В `.env` укажите `DATABASE_URL` и длинный `SESSION_PEPPER`. Для пробного входа без Discord добавьте `ALLOW_DEV_LOGIN=true`.

```bash
npx prisma migrate deploy
npm run dev
```

Рабочая база не содержит тестовых сотрудников и дел. Сборник законов сервера записывается при старте API. Команда `npm run db:seed` загружает демонстрационные записи только если в окружении явно задано `SEED_DEMO=true`, и отказывается это делать при `NODE_ENV=production`.

Для локальной проверки без Discord можно включить `ALLOW_DEV_LOGIN=true` и отдельно засеять персонажей. На рабочем сервере этот флаг запрещён: API не запустится.

API слушает `http://localhost:3000`. Проверка: `http://localhost:3000/health` должен вернуть `{"ok":true,"db":"up"}`.

Отдельные процессы:

```bash
npm run dev:api
npm run dev:bot
```

## Сборка Windows

Перед сборкой замените адрес в `apps/desktop/.env.production` на публичный HTTPS-адрес сервиса `mdt-api`.

```bash
npm run build:win
```

Установщик появится в `apps/desktop/release` под именем `Sheriff-MDT-Setup-<версия>.exe`. Первую сборку сотрудники ставят вручную. Следующие версии администратор отправляет во вкладке «Обновление»: у всех, кто в этот момент в программе, появляется сообщение, файл скачивается, и программа обновляется. База и бот остаются на Railway.

## Права

Права проверяются на сервере при каждом запросе. Скрытие кнопки в окне не заменяет эту проверку. Стартовые должности: администратор, шериф, старший помощник шерифа, помощник шерифа, заместитель, наблюдатель. Администратор может изменить набор прав роли, не переписывая приложение. Право `admin.access` открывает всю систему и не дробится.

Первый администратор появляется только из `BOOTSTRAP_DISCORD_IDS`: это настоящие числовые Discord ID через запятую. При первом входе им выдаётся роль администратора.

## Деньги и склад

Суммы хранятся в центах. Баланс департамента считается на сервере как сумма доходов минус сумма расходов. Клиент не присылает новый баланс. Оплаченный штраф становится доходом только если в настройках включено «Проводить оплаченный штраф в доход». Выдача и возврат снаряжения идут одной транзакцией вместе с остатком склада.

## Язык

Интерфейс русский. Код языка собран в `apps/desktop/src/locale.ts`: сейчас `ru`, рядом заготовлены `en` и `de`. Подписи статусов лежат в `apps/desktop/src/format.ts`.

## Проверки

```bash
npm test
npm run lint
```

`npm test` проверяет права, суммы штрафов, склад, сессии и разбор архива без базы. Сквозные сценарии с PostgreSQL запускаются вручную через тестовый вход.
